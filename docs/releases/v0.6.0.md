## 中文

常用置顶成为首页，并新增网站图标与桌面视图。

- 打开应用默认进入「常用置顶」；还没有置顶时进入「全部收藏」。
- 编辑收藏时可点「获取网站图标」：服务器读取网页声明的图标或 `/favicon.ico`，只接受 PNG、ICO、SVG 等图片格式且不超过约 70 KiB，以 data URI 随收藏保存；可重新获取或移除。图标显示在列表、卡片、精选区和桌面视图中。
- 浏览器导出的 HTML 书签中的图标在导入时保留，HTML 导出也会带上图标。
- 常用置顶新增「桌面视图」：小图标网格，可拖到任意位置，拖到其他图标上互换，或聚焦后用 Alt + 方向键移动。位置保存在服务器偏好中，各设备一致；窄屏放不下的图标自动顺延，不会覆盖宽屏布局。图标悬停或右键可直接编辑。
- 常用置顶的布局（列表 / 卡片 / 桌面）单独记忆。

触屏设备可浏览和打开桌面视图中的图标，调整位置需要鼠标或键盘。获取图标时服务器会访问你填写的网址（包括内网地址），仅限登录用户触发。

升级：在「设置与迁移 → 版本与更新」中检查并安装；或下载对应平台的 `bookmarkd-*` 可执行文件，使用 `SHA256SUMS` 校验，备份数据后替换并重启。数据结构仍为 schema 1，新增字段向后兼容；不需要数据迁移。

此版本继续标记为预发布：尚未完成实机 Passkey 兼容性矩阵及独立安全审查。

## English

Pinned bookmarks become the home view, with site icons and a desktop view.

- The app opens on pinned bookmarks, or the whole library when nothing is pinned.
- When editing a bookmark, “获取网站图标” makes the server read the page's declared icon or `/favicon.ico`, accept only PNG, ICO, SVG and similar images under about 70 KiB, and store it with the bookmark as a data URI; it can be refreshed or removed. Icons appear in the list, cards, shelf, and desktop view.
- Icons in browser-exported HTML bookmarks are kept on import, and HTML exports include them.
- Pinned bookmarks gain a desktop view: a grid of small icons you can drag anywhere, swap by dropping onto another icon, or move with Alt + arrow keys. Positions are saved in server preferences and shared across devices; icons that do not fit a narrow screen flow into free cells without overwriting wider layouts. Hover or right-click an icon to edit it.
- The pinned view remembers its own layout (list, cards, or desktop).

Touch devices can browse and open desktop icons; rearranging needs a mouse or keyboard. Fetching an icon makes the server request the URL you entered (including private network addresses); only the signed-in owner can trigger it.

Upgrade from Settings → “版本与更新”, or download the matching `bookmarkd-*` executable, verify `SHA256SUMS`, back up your data, replace the executable, and restart. Storage remains schema 1 and the new fields are backward compatible; no data migration is required.

This remains a prerelease pending physical Passkey device coverage and independent security review.
