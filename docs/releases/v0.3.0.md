## 中文

界面整体改版：文件夹改为在侧栏直接管理，列表信息更完整，手机端改为卡片布局。

- 侧栏「文件夹」旁新增 ＋，原地输入名称即可创建；悬停文件夹点 ⋯ 或右键，可新建子文件夹、重命名和删除。
- 删除文件夹改为确认弹窗，说明子文件夹数量，并可选择保留收藏（移到收件箱）或连同收藏移入回收站。
- 有子目录的文件夹可折叠，整个文件夹分组也可收起，折叠状态保存在当前浏览器。
- 列表新增「文件夹」列（全部、置顶、搜索与筛选结果中显示），点击可跳转；网址列改为只显示域名。
- 复制、编辑按钮紧跟标题，悬停时显示；标签改为胶囊样式，当前筛选标签高亮并可一键清除。
- 首字母图标按站点生成固定配色，便于区分；不加载第三方 favicon。
- 手机端改为两行卡片：标题，以及域名、文件夹和标签；触屏隐藏拖拽手柄，点击遮罩关闭导航。
- 按 `/` 聚焦搜索，Esc 清空；「整理」更名为「批量操作」；拖拽提示仅在拖动时显示。
- 设置页：修复配色选项文字竖排；导入改为拖放区；Bookmarklet 改为可拖到书签栏的按钮。
- 统一使用 SVG 图标，移除装饰性标语。
- 修复快速切换目录时较早的请求覆盖较新结果的问题。

下载对应平台的 `bookmarkd-*` 可执行文件，并使用 `SHA256SUMS` 校验。升级前备份数据，停止旧进程后替换可执行文件，再使用原配置启动。数据结构仍为 schema 1；本版本不需要数据迁移。

此版本继续标记为预发布：尚未完成实机 Passkey 兼容性矩阵及独立安全审查。

## English

A redesigned interface: folders are managed directly in the sidebar, the list shows more context, and phones use a card layout.

- Create folders inline with ＋ next to “文件夹”; hover a folder and select ⋯, or right-click it, to add a subfolder, rename, or delete.
- Deleting a folder opens a confirmation dialog that states how many subfolders are affected and lets you keep its bookmarks (moved to Inbox) or move them to trash as well.
- Folders with children, and the whole folder section, can be collapsed; the state is remembered in the current browser.
- New Folder column in All, Pinned, search, and filtered views, linking to the folder; the URL column now shows only the domain.
- Copy and edit actions sit next to the title and appear on hover; tags are pills, and the active tag filter is highlighted and clearable.
- Letter icons get a stable per-site color; no third-party favicons are loaded.
- Phones show two-line cards with title, domain, folder, and tags; touch devices hide drag handles, and tapping the backdrop closes navigation.
- Press `/` to focus search and Esc to clear it; “整理” is now “批量操作”; drag hints appear only while dragging.
- Settings: fixed palette names wrapping vertically; import is a drop zone; the bookmarklet is a button you drag to the bookmarks bar.
- Consistent SVG icons; decorative slogans removed.
- Fix older responses overwriting newer results when switching folders quickly.

Download the matching `bookmarkd-*` executable and verify `SHA256SUMS`. Back up your data, stop the previous process, replace the executable, and restart with your existing configuration. Storage remains schema 1; no data migration is required.

This remains a prerelease pending physical Passkey device coverage and independent security review.
