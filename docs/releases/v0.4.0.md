## 中文

新增从 GitHub Releases 检查与安装更新。

- 「设置与迁移 → 版本与更新」显示当前版本、上次检查时间和新版本更新说明，可「立即检查」。
- 可设置每天或每周固定时间（服务器时区）自动检查；渠道可选「包含预发布版本」（默认）或「仅正式版本」。自动检查默认关闭，开启后服务器会访问 `api.github.com`。
- 定时检查只提醒：发现新版本时侧栏「设置与迁移」出现红点，不会自动安装。
- 点击「更新到 vX」并再次验证 Passkey 后安装：下载本平台文件，用同一 Release 的 `SHA256SUMS` 校验，运行新程序自检，备份数据到 `data/backups/pre-update-*`，替换程序（旧程序保留为 `bookmarkd.old`），并在原进程内重启（PID 不变，systemd 无需改配置）。
- 新增命令：`bookmarkd update check`、`update install --yes`、`update rollback --yes`。
- Windows 仅提醒并提供下载链接，不支持自动安装。程序所在目录必须对运行用户可写。

**本次需要手动升级一次**：v0.3.0 及更早版本没有更新功能。下载对应平台的 `bookmarkd-*` 可执行文件，并使用 `SHA256SUMS` 校验；备份数据，停止旧进程后替换可执行文件，再使用原配置启动。之后的版本可在页面上更新。数据结构仍为 schema 1；不需要数据迁移。

`SHA256SUMS` 能发现下载损坏，但无法防御 Release 本身被替换。此版本继续标记为预发布：尚未完成实机 Passkey 兼容性矩阵及独立安全审查。

## English

Adds checking for and installing updates from GitHub Releases.

- Settings → “版本与更新” shows the current version, the last check time, and release notes for a newer version, with “check now”.
- Optional daily or weekly checks at a fixed server-local time; the channel is prereleases included (default) or stable only. Automatic checks are off by default; when enabled, the server contacts `api.github.com`.
- Scheduled checks only notify: a red dot appears on “设置与迁移”; nothing installs automatically.
- Selecting “更新到 vX” and verifying with your Passkey again installs it: the server downloads this platform's file, verifies it against the same release's `SHA256SUMS`, runs a self-check of the new binary, backs up data to `data/backups/pre-update-*`, swaps the executable (keeping the previous one as `bookmarkd.old`), and restarts in place (same PID; no systemd changes needed).
- New commands: `bookmarkd update check`, `update install --yes`, `update rollback --yes`.
- Windows is check-only with a download link. The executable's directory must be writable by the service user.

**Upgrade manually this once:** v0.3.0 and earlier lack the updater. Download the matching `bookmarkd-*` executable and verify `SHA256SUMS`; back up your data, stop the previous process, replace the executable, and restart with your existing configuration. Later versions can be installed from the web UI. Storage remains schema 1; no data migration is required.

`SHA256SUMS` detects corrupted downloads but cannot protect against a replaced release. This remains a prerelease pending physical Passkey device coverage and independent security review.
