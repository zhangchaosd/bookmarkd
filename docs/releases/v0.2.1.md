## 中文

包含未完成发布的 v0.2.0 功能，并修复异步加载覆盖主题预览的问题。

- 紧凑三列表格：名称与图标、标签、网址；默认行高 32px，紧凑模式 28px。
- 收藏支持拖拽排序，拖入目录或拖到收件箱移出目录。
- 目录支持拖拽嵌套、同级排序和移回根目录；移动采用事务与版本检查，防止循环和并发覆盖。
- 新增森林绿、海洋蓝、鸢尾紫、暖琥珀、石墨灰五组配色，均支持浅色、深色及跟随系统，偏好可保存。
- 修复认证器随机 ID 以连字符开头时的命令行集成测试问题。

下载对应平台的 `bookmarkd-*` 可执行文件，并使用 `SHA256SUMS` 校验。升级前备份数据，停止旧进程后替换可执行文件，再使用原配置启动。数据结构仍为 schema 1；本版本不需要数据迁移。

此版本继续标记为预发布：尚未完成实机 Passkey 兼容性矩阵及独立安全审查。拖拽针对桌面鼠标；触屏使用编辑与批量移动。

## English

Includes the unpublished v0.2.0 feature set and fixes asynchronous loading overwriting appearance previews.

- Compact name/icon, tags, and URL table: 32px default rows and 28px compact rows.
- Drag bookmarks to reorder, into folders, or onto Inbox to move them out.
- Drag folders to nest, reorder siblings, or move to root. Transactional moves and version checks prevent cycles and concurrent overwrites.
- Five palettes: Forest, Ocean, Iris, Amber, and Graphite. Each supports light, dark, and system appearance with saved preferences.
- Fix CLI integration tests for random credential IDs beginning with a hyphen.

Download the matching `bookmarkd-*` executable and verify `SHA256SUMS`. Back up your data, stop the previous process, replace the executable, and restart with your existing configuration. Storage remains schema 1; no data migration is required.

This remains a prerelease pending physical Passkey device coverage and independent security review. Dragging targets desktop mouse input; touch devices retain editing and batch moves.
